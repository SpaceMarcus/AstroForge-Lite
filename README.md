# AstroForge Lite · Interactive Demo

[Open the demo](https://spacemarcus.github.io/AstroForge-Lite/)

Build a component graph, configure cooling coverage and explore six interactive cooling charts on desktop or mobile.

**Representative demonstration only.** All calculated outputs are synthetic indices from 0 to 100, not temperatures, pressures, performance predictions, validation or design guidance. Inputs with engineering units are user-supplied project settings. The demo does not use thermophysical property tables or the private AstroForge calculation engine. Changing coolant labels does not perform a real fluid comparison.

Cooling geometry and direction change the illustrative curves and system indices. The model is deterministic and deliberately uncalibrated. No backend, account or payment is required. Projects stay in the browser and can be exported.

The full AstroForge project remains private and is planned from 2027.

This repository contains only the public demonstration, with a fresh history. It is not a release of AstroForge's engineering models.
